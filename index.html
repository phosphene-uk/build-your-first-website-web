Build your first website

A step-by-step guide to building your own website: from a single page you write by hand, to a site with shared parts, written content and a little JavaScript, published for free with GitHub Pages.

You don’t need any experience. If you can use a computer, you can follow it, and every part ends with a working website online at its own address.

Part 1 is free to read here. It takes you from an empty folder to a two-page website that anyone can visit.

Start reading Part 1

By the end of this part, your first web page will be online, at an address you can share with anyone. You’ll need a code editor, a web browser and a free GitHub account, which you’ll create along the way.
